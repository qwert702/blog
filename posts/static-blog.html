把个人博客做成一块可长期维护的岩层

2026-11-01 · 5 分钟阅读

旧博客是一个 Vite + React 的单页应用。它能跑，但首页依赖一段远程视频，正文靠 JavaScript 渲染，搜索引擎和分享卡片都很难真正读到内容。对一个准备长期写东西的博客来说，这不是一个合适的底座。

这次改造只坚持三件事

  1. 内容先于特效。 文章页必须是普通 HTML，禁用 JavaScript 也能读；
  2. 首屏要轻。 不再自动播放远程视频，改用静态封面与排版本身建立气质；
  3. 可迁移。 文章以 Markdown/HTML 保存，换生成器、换服务器都不需要重写内容。

视觉：地质与时间

原来的 tagline 是“时光镌刻于层岩之中”。这次把它变成了真正的视觉语言：暖白岩层、墨色文字、单一矿物青强调色，衬线标题配高可读正文。没有大渐变，没有无意义的玻璃拟态。

好设计不是把元素堆满，而是让读者忘记界面，直接进入文字。

技术选择

当前版本使用静态 HTML/CSS/JS：没有运行时框架、没有客户端路由、没有构建依赖。文章规模变大后，可以平滑迁移到 Astro 或 Hugo；页面结构和 URL 不变，迁移成本可控。

这也是一种“可逆优先”：先用最简单的结构上线，再根据真实写作量决定要不要引入生成器。
